# GATE 2027 Prep Tracker & IISc OP Focus Blocker

A Chrome Extension for serious GATE 2027 CSE aspirants featuring real-time dashboard sync and the iconic **IISc OP YouTube Focus Blocker**.

## 🏛️ Features

- ⏳ **Live GATE 2027 Countdown** — Real-time countdown to Feb 1, 2027.
- 🏛️ **IISc OP YouTube Focus Blocker** — Blocks YouTube distractions (Shorts, Home feed, entertainment videos) with an aesthetic high-resolution photo of IISc Bangalore and the savage wake-up call: *"Phir ye tumse na ho payega!"*.
- 👑 **Admin Whitelist Exception** — Dedicated exception for `yash.dr2004@gmail.com` with full unrestricted YouTube access.
- 📚 **GO Classes Study Mode** — Permits only official GO Classes GATE CSE study lectures on YouTube for active studying.
- 🎯 **Today's Focus Time** — Synced live from your study dashboard.
- 📋 **Today's Todo Checklist** — Real-time tracking of daily study targets.
- 🚀 **Quick Launch** — 1-click launch to your GATE 2027 study dashboard.

## 🚀 Installation Guide

1. Open Google Chrome and go to `chrome://extensions`
2. Enable **Developer Mode** (toggle in the top-right corner)
3. Click **"Load unpacked"**
4. Select the `extension` folder from this project (or extracted from `extension.zip`)
5. Pin the extension to your toolbar!

## 🔐 How the Whitelist & Blocking Works

- **Admin Account (`yash.dr2004@gmail.com`)**:
  - Automatically detected when logged into the dashboard, or set in the extension popup.
  - YouTube is 100% allowed without any blocking screens or restrictions.
- **Other Accounts / Not Logged In**:
  - YouTube Home, Shorts, Feed, and non-study videos are blocked with the IISc Bangalore OP overlay.
  - Only official GO Classes lectures are allowed for study purposes.
